# Aortic-heart-defect
Machine learning pipeline for aortic valve disease classification using ECG indicators and antropometric data with patient-wise GroupKFold cross-validation.(Конвейер машинного обучения для классификации пороков аортального клапана по показателям ЭКГ и антропометрическим данным с кросс-валидацией по пациентам).
